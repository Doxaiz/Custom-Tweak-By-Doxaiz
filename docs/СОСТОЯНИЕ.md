## 2. Что сделано в 0.4.1

1. **Предел ожидания у каждой команды свой.** Раньше у всех команд канала был один предел — 10 секунд.
   Применение твиков с точкой восстановления и живой запуск идут дольше, и человек видел «служба не ответила»,
   хотя служба продолжала работать. Теперь: `ping`/`status` — 10 с, `realtime-start` — 180 с,
   применение твиков и откат — 300 с (`EngineCommandCatalog.TimeoutSeconds`).
2. **Отказ называет найденное соединение.** Если игры нет, но в таблице соединений есть публичные потоки
   процессов не из каталога, программа говорит это прямо: имя процесса, адрес:порт, до трёх лучших, и что
   делать (добавить игру в список известных). Раньше было сухое «игра не найдена».
3. **Выбор кандидата — по «игровости», а не по номеру процесса.** Живой прогон `39036680619` показал, что
   первым в тексте оказывался `windowsazureguestagent.exe` с портом 32526. Теперь известный игровой порт +6,
   служебные (DNS/NTP) −4, порядок `Score desc, PID asc`.
4. **Живая проверка шага 3б.** Скрипт `tools/ui-walkthrough.ps1` поднимает настоящее TCP-соединение на игровой
   порт 3074 к публичному адресу (процесс — не из списка игр), нажимает кнопку и требует, чтобы в ответе были
   и «не входит в список известных игр», и порт `3074`. Нет сети на этот порт — шаг честно пишет «ПРОПУЩЕНО»,
   а не красит прогон в красный.

## 5. Подводные камни песочницы (уже проверены на опыте)

- **`.git/config` не попадает в снимок воркспейса.** После восстановления окружения `origin` и `user.name`
  пропадают, а `HEAD` может откатиться на старый коммит. Лечение:
  `git remote add origin https://github.com/Doxaiz/Custom-Tweak-By-Doxaiz.git`,
  `git fetch origin main`, `git reset --mixed origin/main` — файлы не меняются, история восстанавливается.
- **`bin/` и `obj/` раздувают снимок.** Они не в списке исключений, поэтому после локальных сборок воркспейс
  легко перевалить за 128 МБ («Workspace over budget»). Перед паузой чистить:
  `find . -type d \( -name bin -o -name obj \) -prune -exec rm -rf {} +`
  Сборка для проверок — с `--artifacts-path` в `/var/tmp`.
- `python3 tools/render_ui_preview.py` **без аргумента** падает: нужен `docs/catalog.json`.
- `gh run download` вне папки git-репозитория падает: запускать из `pingforge/`.
- PowerShell: `.ps1` должен иметь **ровно одну** метку UTF-8 BOM; inline `run:` в YAML — только ASCII.

## 6. Правила, которые нельзя нарушать

- Программа при запуске **ничего не меняет**; изменения — только по нажатию кнопки и с подтверждением.
- Любое изменение — через снапшот и точку восстановления, с честным откатом.
- Запрещено: инжект DLL и доступ к памяти игры, отключение анти-читов/Defender/брандмауэра/обновлений/UAC/
  подписи драйверов, подмена MAC/IP, телеметрия, обещания «пинг 0».
- Выигрыш заявляется **только измеренный**: «пинг снизился с X до Y» — факт из замера, иначе «заметного
  выигрыша нет» или «стало хуже, причина в маршруте».
- Имя приложения — «Custom Tweak By Doxaiz»; пространства имён, пути и имя репозитория не переименовывать.
- Интерфейс и структуру по BoosterX не переделывать; шесть разделов, мастер первого запуска, лаунчер «Открыть».
