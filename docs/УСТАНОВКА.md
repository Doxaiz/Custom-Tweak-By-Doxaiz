# Установка и первый запуск

Коротко: запустить установщик, открыть программу, нажать кнопку. До нажатия кнопки
«Оптимизировать соединение» программа ничего не меняет.

## Что нужно

| | Требование |
|---|---|
| Windows | 10 или 11 (64-разрядная) |
| Права | администратор — только для установки службы |
| .NET | **не нужен** ни установщику, ни автономной сборке; компактной сборке нужен [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) |
| Свободное место | ≈250 МБ — включая место под журнал и снапшоты в `%ProgramData%\PingForge` |

## Что скачивать — какой файл кому

| Файл | Размер | Кому |
|---|---|---|
| `CustomTweakByDoxaiz-Setup-<версия>.exe` | ≈80 МБ | **обычный случай: установщик.** Двойной щелчок и «Далее» |
| `CustomTweakByDoxaiz-<версия>.exe` | ≈75 МБ | программа одним файлом, без установки; службу ставить отдельно |
| `CustomTweakByDoxaiz.Service-<версия>.exe` | ≈40 МБ | служба отдельным файлом — для способа «без установщика» |
| `CustomTweakByDoxaiz-portable-win-x64.zip` | ≈80 МБ | автономный архив: .NET не нужен, внутри оба .exe, скрипты и эта инструкция |
| `CustomTweakByDoxaiz-compact-win-x64.zip` | ≈3 МБ | если .NET 10 уже стоит или не жалко его поставить |
| `SHA256SUMS.txt` | — | контрольные суммы: сверить, что скачалось ровно собранное |

Во всех случаях ставится одно и то же: программа, служба, скрипты и эта инструкция.

Все файлы ниже лежат на странице
[**Releases**](https://github.com/Doxaiz/Custom-Tweak-By-Doxaiz/releases/latest) — это те же файлы,
которые собирает автоматическая сборка.

## Способ 1: установщик (обычный случай)

1. Запустите `CustomTweakByDoxaiz-Setup-<версия>.exe`. Windows спросит разрешение — установщику нужны
   права администратора, чтобы зарегистрировать службу.
2. Windows может показать предупреждение SmartScreen: установщик пока не подписан сертификатом EV.
   Нажмите «Подробнее» → «Выполнить в любом случае».
3. В установщике можно снять галочки: ярлык на рабочем столе, ярлык в меню «Пуск», саму службу.
   **Службу лучше оставить включённой** — без неё программа запустится, но менять настройки не сможет.
4. Готово: программа установлена в `C:\Program Files\Custom Tweak By Doxaiz`, служба `PingForge`
   зарегистрирована и запущена.

Удаление — обычное, из «Программ и компонентов». Служба снимается, файлы удаляются, а журнал
и снапшоты в `%ProgramData%\PingForge` остаются: по ним программа возвращала прежние настройки.
Установщик спросит отдельно, удалять ли и их.

## Способ 2: без установщика (архив или отдельные .exe)

Если установщик не нужен — так тоже можно.

1. Распакуйте архив **целиком** в отдельную папку (не запускайте файлы прямо из архива).
2. Щёлкните правой кнопкой по `install-service.ps1` → **«Выполнить с помощью PowerShell»**.

   Если Windows не даёт запускать скрипты, откройте PowerShell от имени администратора и выполните:

   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   cd "путь\к\распакованному\архиву"
   .\install-service.ps1
   ```

3. Скрипт скопирует файлы в `C:\Program Files\Custom Tweak By Doxaiz`, зарегистрирует службу
   с именем `PingForge`, настроит перезапуск при сбое и добавит ярлык в меню «Пуск».

## Первый запуск

1. Откройте **Custom Tweak By Doxaiz** из меню «Пуск».
2. Нажмите **«Оптимизировать соединение»**.

Что произойдёт: программа найдёт запущенную игру, замерит задержку «до», выберет путь до игрового
сервера, пометит пакеты игры приоритетом и включит подходящие настройки Windows. Всё, что она изменила,
видно в разделе «Журнал» — и там же кнопка возврата.

Программа не начнёт работу сама: при запуске она молчит и только показывает состояние.

## Полезные ключи установки

Установщик умеет ставиться без вопросов — это удобно скриптам и проверкам:

```powershell
.\CustomTweakByDoxaiz-Setup-0.2.0.exe /S      # тихая установка: без окон и вопросов
"%ProgramFiles%\Custom Tweak By Doxaiz\Uninstall.exe" /S   # тихое удаление
```

У скрипта установки свои ключи:

```powershell
.\install-service.ps1 -InstallDir "D:\Утилиты\CustomTweak"   # своя папка
.\install-service.ps1 -NoShortcut                            # без ярлыка
.\install-service.ps1 -SkipService                           # только файлы, без службы (для проверки)
.\install-service.ps1 -Force                                 # переустановить поверх прежней версии
```

## Снятие

Поставлено установщиком — удаляйте так же: «Программы и компоненты» → **Custom Tweak By Doxaiz** →
«Удалить». Служба снимается, файлы и ярлыки удаляются, а данные остаются; удалить их тоже
установщик спросит отдельно.

Ставили архивом — снимете скриптом:

```powershell
.\uninstall-service.ps1              # служба и файлы, данные остаются
.\uninstall-service.ps1 -RemoveData  # вместе с журналом и снапшотами
```

Скрипт снятия останавливает службу, удаляет её, убирает файлы и ярлык. Данные
(`%ProgramData%\PingForge`) по умолчанию **сохраняются**: там журнал изменений и снапшоты, по которым
можно вернуть прежние настройки.

## Программа не открылась

Если после двойного щелчка по программе ничего не произошло — не запускайте её много раз подряд.
Сначала посмотрите, что уже есть:

**1. Журнал запуска.** Программа пишет его с первой же миллисекунды:

```powershell
notepad "$env:LOCALAPPDATA\CustomTweakByDoxaiz\app-start.log"
```

- **Файла нет вообще** — программа не дошла даже до своей первой строки. Значит её не пустила система.
- **Файл есть** — в нём по шагам видно, на чём остановилось, и какая ошибка была.

**2. Программа запускается, но окна нет.** Оставьте её в трее или запустите с проверкой:

```powershell
# посмотреть, что происходит, ничего не показывая: результат ляжет в тот же журнал
.\CustomTweakByDoxaiz-0.2.2.exe --self-check
```

Код возврата: `0` — всё собралось, `21` — каталог, `22` — модели, `23` — окно, `4` — не уложилась в две минуты.

**3. Программу не пускает система.** Так выглядит карантин антивируса и SmartScreen — окна нет,
ошибки нет, ничего нет:

```powershell
# снять метку «из интернета» (после скачивания файл помечен; Windows иногда молча не пускает такие)
Unblock-File .\CustomTweakByDoxaiz-0.2.2.exe

# проверить, не забрал ли файл Защитник Windows
Get-MpThreatDetection | Select-Object -Last 5 InitialDetectionTime, Resources
```

Если файл в карантине — добавьте его в исключения или соберите программу у себя: `dotnet publish`
(см. «Сборка своими руками» в README).

**4. Что сказала Windows об ошибке.** Если программа падала, Windows помнит это даже без нашего журнала:

```powershell
Get-WinEvent -LogName Application -MaxEvents 60 |
  Where-Object { $_.ProviderName -in @('.NET Runtime', 'Application Error', 'Windows Error Reporting') } |
  Select-Object TimeCreated, ProviderName, Message -First 5 | Format-List
```

**5. Передать сведения автору.** Достаточно двух файлов: журнал запуска из пункта 1 и журнал службы
`%ProgramData%\PingForge\service.log`. По ним видно всё, что происходило, и ничего личного там нет.

## Если что-то не работает

| Что видно | Что делать |
|---|---|
| «Служба PingForge не отвечает» | Проверьте службу: `Get-Service PingForge`. Не запущена — `Start-Service PingForge`. |
| Программа работает, но «будут только замеры» | Служба не запущена или нет прав. Настройки Windows без неё не меняются — это не сбой, а защита. |
| Точка восстановления не создалась | Смотрите причину в окне: защита системы выключена или суточный лимит Windows. Твики применятся всё равно, откат работает средствами программы. |
| Хочу посмотреть, что делает служба | `%ProgramData%\PingForge\service.log` — журнал службы. |
| Служба не ставится | Запустите PowerShell от имени администратора и повторите. Если ставили установщиком — рядом с программой остался файл `install-service.log`: в нём видно, что именно не получилось. |
| Хочу проверить, что служба отвечает, не открывая окно | `PingForge.EngineSmoke.exe` (в артефактах сборки): показывает ответы службы и ничего не меняет. |
| Программа открывается, но пишет «будут только замеры» | Служба не установлена или не запущена. Поставьте её установщиком: без службы менять настройки Windows нечем. |
| Хочу запустить без окон-сообщений | `CustomTweakByDoxaiz.exe --quiet` — все сообщения пойдут в журнал запуска, диалогов не будет. |

## Что программа не делает

Никогда и ни при каких настройках:

- не влезает в процесс игры: ни внедрения DLL, ни чтения памяти игры;
- не выключает и не обходит анти-читы;
- не отключает Защитник Windows, брандмауэр, обновления и контроль учётных записей;
- не подменяет MAC- и IP-адреса;
- не меняет настройки роутера за вас;
- не собирает и не отправляет ваши данные — телеметрии нет;
- не меняет ничего без подтверждения и без снапшота прежних значений.
