# Журнал изменений — Custom Tweak By Doxaiz

Все важные изменения по версиям. Формат: Added / Changed / Fixed / Security.

## [0.5.7] — 2026-10-20
### Added
- Команда «Вернуть всё как было» (трей + Настройки): останавливает оптимизацию → снимает QoS → маршруты → откатывает твики → проверяет остатки; честный отчёт по шагам.
- Политика хранения снапшотов: хранить последние 10, не удалять новее 30 дней, снапшоты с незакрытыми операциями не удаляются никогда.
- Экран «Сколько занимает база» в О программе: путь к `pingforge.db`, размер, число снапшотов и записей, кнопка «Почистить».

### Changed
- Лобби Fortnite creative теперь показывается как запущенная игра с подсказкой «зайдите в матч», а не «игра не найдена».

### Fixed
- Определён удалённый собеседник UDP через ETW (UDP 0.0.0.0:0 теперь находится).
- Кэширование вердикта маршрута по процессу **и** адресу сервера — матчмейкер с новым сервером перемеряется.

## [0.5.6] — 2026-10-20
### Added
- Экран «Что изменилось» после применения: было → стало, статусы, кнопка «Вернуть только это».
- Журнал: фильтры по типу/статусу/дате, поиск, пагинация «Показано X из Y», CSV-выгрузка.
- Проверка обновлений по кнопке с показом SHA-256.

### Changed
- Журнал хранит до 200 записей по умолчанию (limit 500), вместо 20.

## [0.5.5] — 2026-10-20
### Added
- Логи с ротацией 5 МБ × 3 и пакет для поддержки (ZIP ≤20 МБ).
- Регионы и порты игр из GameRouteCatalog, честная карточка DNS.
- Сессии истории (v5 схема) + вкладка Сессии в Журнале.

### Fixed
- UAC-проверка по токену клиента, а не службы (C1).

## [0.4.1] — 2026-10-10
### Added
- Базовые твики (TCP, QoS, NIC), снапшоты, откат, профили.

### Fixed
- Общий файл настроек под мьютексом, .bak и карантин битого JSON.

---
Известные ограничения (актуально для 0.5.7):
- Установщик без подписи EV — SmartScreen предупреждает; проверяйте SHA-256 из SHA256SUMS.txt в релизе.
- Маршрут требует выбранного узла и живой игры; без них — честный отказ, а не выдумка.
